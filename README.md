# Hand-gesture-recognition-robot
In this project, we designed and implemented an intelligent mobile robot capable of recognizing hand gestures through a live camera feed. The robot interprets gesture-based commands and responds in real time to control its movement direction. The system integrates computer vision and machine learning techniques to enable perception, decision-making, and immediate response. The trained gesture recognition model achieved approximately 98% accuracy during testing; however,some gestures with similar hand patterns occasionally caused misclassification. Overall, the project demonstrates the feasibility of integrating gesture recognition and cognitive robotics concepts into an interactive robotic system
